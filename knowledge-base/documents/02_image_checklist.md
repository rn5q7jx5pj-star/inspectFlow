# 图片输入与采集检查清单

## INPUT-01：上传文件必须满足什么条件

条目编号：INPUT-01  
适用范围：InspectFlow POST /v1/detections 接口  
文档版本：demo-v1；核对日期：2026-11-01  
内容性质：项目事实  
来源：SRC-API

通过 multipart 表单中的 image 文件字段上传一张非空图片。单个文件不能超过 5 MiB（5,242,880 字节），整个 HTTP 请求体不能超过 6 MiB（6,291,456 字节），后者包含表单开销。文件内容必须能被服务中的 OpenCV 成功解码；仅修改扩展名或 MIME 类型不能使非图片变为有效图片。缺少字段、空文件或无法解码会触发错误。格式能被解码不代表样本属于模型适用类别，服务没有因此完成业务适用性验证。超过整个请求体限制时，可能在进入业务处理前被 HTTP 库拒绝，不能保证收到同样的业务 JSON 错误格式。

## INPUT-02：上传图片后执行哪些预处理

条目编号：INPUT-02  
适用范围：InspectFlow 当前固定输入协议的 C++ 服务  
文档版本：demo-v1；核对日期：2026-11-01  
内容性质：项目事实  
来源：SRC-PREPROCESS、SRC-ENGINE、SRC-API

服务以彩色方式解码图片，然后将 BGR 转为 RGB，使用线性插值缩放至 256×256，将像素除以 255 转成 float32，并以 CHW 顺序组织为 [1,3,256,256] 输入。上传原图不要求已经是 256×256，也不需要在插件中提前归一化。这里描述的是模型外的 C++ 处理，不代表 ONNX 图内部没有其他变换。当前缩放不是等比例补边；这段实现没有额外完成自动目标定位、光照校正或业务采集质量审核。

## INPUT-03：演示采集时人工检查什么

条目编号：INPUT-03  
适用范围：当前 bottle 示例模型的学习演示  
文档版本：demo-v1；核对日期：2026-11-01  
内容性质：演示建议，不是工业采集标准；未实现自动审核  
来源：SRC-MODEL-CONFIG、DEMO-DESIGN

演示前核对所加载模型是否对应 bottle；优先使用与该模型训练和验证条件相符的样本。人工检查目标是否可见，是否存在明显模糊、严重过曝、遮挡或与参考样本明显不同的视角、背景。发现这些问题时，记录原因并重新采集或转人工判断，不直接把模型异常判定解释为产品缺陷。保留原始图片和必要采集信息，不为得到正常结果而反复修饰图片。本项目尚未给出经验证的光照、距离、清晰度数值标准，因此本条不规定照度、相机距离或曝光参数。
